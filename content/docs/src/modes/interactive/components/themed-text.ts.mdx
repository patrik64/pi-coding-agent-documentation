Plain `Text` bakes ANSI color codes into its string when it is constructed. If the theme changes later, that string keeps the old colors. `ThemedText` fixes this by storing a `build` function instead of a string.

The TUI calls `invalidate()` on every component when the theme changes (see [theme.ts](/docs/src/modes/interactive/theme/theme.ts) and the [theme-controller.ts](/docs/src/modes/interactive/theme/theme-controller.ts)), which is the hook this class uses.

<Scrollycoding>

## !!steps The contract in the doc comment

The comment states the rule: `build` must return the same content every time except for colors. Data that changes must be snapshotted first or followed by an explicit `invalidate()`.

```ts ! themed-text.ts
/**
 * Text whose content applies theme colors. Plain `Text` keeps the colors its string was built with, so
 * a theme change, or the system theme receiving the terminal's colors, would leave it stale. This
 * rebuilds the string from `build` after every invalidation, which the UI performs on theme changes.
 *
 * `build` must return the same content each time, apart from colors. Snapshot changing data before
 * creating the component, or call `invalidate()` after changing state that `build` reads.
 */
export class ThemedText extends Text {
	// !mark(1:2)
	private readonly build: () => string;
	private stale = true;

	constructor(build: () => string, paddingX = 1, paddingY = 1) {
		super("", paddingX, paddingY);
		this.build = build;
	}
```

## !!steps Invalidate marks the text stale

Invalidating does not rebuild immediately. It only sets a flag, so a burst of invalidations costs one rebuild.

```ts ! themed-text.ts
	override invalidate(): void {
		super.invalidate();
		// !mark
		this.stale = true;
	}
```

## !!steps Rebuild lazily on render

The first render also builds, because `stale` starts as `true` and the base constructor receives an empty string. Rebuilding then calls `setText`, which is the normal `Text` path.

```ts ! themed-text.ts
	override render(width: number): string[] {
		// !mark(1:3)
		if (this.stale) {
			this.stale = false;
			this.setText(this.build());
		}
		return super.render(width);
	}
```

Used throughout [interactive-mode.ts](/docs/src/modes/interactive/interactive-mode.ts) for the What's New header, conflict warnings and hint lines that must survive a live theme switch. It adds no state beyond the two fields.
