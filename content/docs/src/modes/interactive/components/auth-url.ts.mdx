During OAuth login the user has to open a long URL. In a terminal that URL wraps
over several lines, and over SSH or inside tmux it often cannot be clicked or
selected as a whole. This small component shows it as an OSC hyperlink and
offers a keyboard copy fallback.

It is used by login screens such as [login-dialog.ts](/docs/src/modes/interactive/components/login-dialog.ts).

<Scrollycoding>

## !!steps Two lines: the link and a hint

The constructor adds the URL as an accent-colored hyperlink, then a second text
line that holds the hint. Hints are rendered through `setHint`, starting with
the copy keybinding from [keybinding-hints.ts](/docs/src/modes/interactive/components/keybinding-hints.ts).

```ts ! auth-url.ts
/**
 * A sign-in URL with a click hint and a copy hint. Hosts call `copy()` when `app.message.copy` is
 * pressed, since a long URL wraps and often cannot be selected or clicked as a whole (SSH, tmux).
 */
export class AuthUrlComponent extends Container {
	readonly url: string;
	private readonly tui: TUI;
	private readonly hint: Text;

	constructor(tui: TUI, url: string) {
		super();
		this.tui = tui;
		this.url = url;
		this.addChild(new Text(theme.fg("accent", hyperlink(url, url)), 1, 0));
		this.hint = new Text("", 1, 0);
		this.addChild(this.hint);
		this.setHint(keyHint("app.message.copy", "to copy"));
	}
```

## !!steps Platform-aware hint

The click hint says Cmd on macOS and Ctrl elsewhere, and is itself a hyperlink to
the URL. `setHint` also calls `requestRender`, because the text changes outside
the normal render cycle.

```ts ! auth-url.ts
	private setHint(suffix: string): void {
		const clickHint = process.platform === "darwin" ? "Cmd+click to open" : "Ctrl+click to open";
		this.hint.setText(`${theme.fg("dim", hyperlink(clickHint, this.url))} ${theme.fg("dim", "•")} ${suffix}`);
		this.tui.requestRender();
	}
```

## !!steps Copying

The host calls `copy()` when the `app.message.copy` key is pressed. Success and
failure are both shown by replacing the hint, using `copyToClipboard` from
[clipboard.ts](/docs/src/utils/clipboard.ts); errors are not thrown to the host.

```ts ! auth-url.ts
	async copy(): Promise<void> {
		try {
			await copyToClipboard(this.url);
			this.setHint(theme.fg("success", "Copied URL to clipboard"));
		} catch (error) {
			this.setHint(theme.fg("error", error instanceof Error ? error.message : String(error)));
		}
	}
```

</Scrollycoding>

The component owns no key handling, so the host must route the copy key to it.
