The edit tool produces a text diff with a compact format: a prefix character (`+`, `-` or space), a padded line number, then the line content. This file turns that text into themed terminal lines. Context lines are dimmed, removals are red and additions are green.

Its one clever feature is intra-line highlighting: when exactly one line was replaced by exactly one line, the changed words are shown in inverse video using the `diff` package's word diff. The diff text itself comes from [edit-diff.ts](/docs/src/core/tools/edit-diff.ts) and is displayed by the edit renderer in [edit.ts](/docs/src/core/tools/renderers/edit.ts); colors come from [theme.ts](/docs/src/modes/interactive/theme/theme.ts).

## !!steps Parsing a diff line

The regex captures the prefix, an optional run of spaces and digits for the line number, and the rest as content. A line that does not match (for example a separator such as an ellipsis line) returns `null` and is later printed as plain context. `replaceTabs` swaps each tab for three spaces so alignment is stable in the terminal.

```ts ! diff.ts
function parseDiffLine(line: string): { prefix: string; lineNum: string; content: string } | null {
	const match = line.match(/^([+-\s])(\s*\d*)\s(.*)$/);
	if (!match) return null;
	return { prefix: match[1], lineNum: match[2], content: match[3] };
}

/**
 * Replace tabs with spaces for consistent rendering.
 */
function replaceTabs(text: string): string {
	return text.replace(/\t/g, "   ");
}
```

## !!steps The main loop and context lines

`renderDiff` walks the lines with an index. Unparseable lines are emitted with the context color. Parsed lines whose prefix is neither plus nor minus are context and keep their number.

```ts ! diff.ts
export function renderDiff(diffText: string, _options: RenderDiffOptions = {}): string {
	const lines = diffText.split("\n");
	const result: string[] = [];

	let i = 0;
	while (i < lines.length) {
		const line = lines[i];
		const parsed = parseDiffLine(line);

		if (!parsed) {
			result.push(theme.fg("toolDiffContext", line));
			i++;
			continue;
		}
```

## !!steps Grouping removed and added runs

On a removal the loop gathers the whole run of consecutive removed lines and then the whole run of added lines that follows. This is how a replaced block is recognized.

```ts ! diff.ts

				i++;
```
