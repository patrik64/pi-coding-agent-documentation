This file draws the pi brand mark in the terminal and decides whether the terminal is able to show it. It is small and has no state apart from three fixed brand colors.

Colors are converted using the current terminal color mode from [theme.ts](/docs/src/modes/interactive/theme/theme.ts), so they degrade properly on 256-color terminals. Branded interactive screens such as [first-time-setup.ts](/docs/src/modes/interactive/components/first-time-setup.ts) are the natural consumers.

<Scrollycoding>

## !!steps Brand colors

Three fixed colors are defined once. They intentionally do not follow the theme.

```ts ! pi-logo.ts
import { backgroundAnsi, foregroundAnsi, isAppleTerminalSession, rgbColor } from "@earendil-works/pi-tui";
import { theme } from "../theme/theme.ts";

const CORAL = rgbColor(228, 138, 122);
const BLUE = rgbColor(79, 142, 179);
const YELLOW = rgbColor(234, 182, 93);
const RESET = "\x1b[0m";
```

## !!steps Drawing with half blocks

Each terminal cell holds two vertically stacked square pixels using the upper half block, lower half block and full block characters. The top line needs a background color for its first cell (blue behind a coral upper half), then the second and third cells, and a trailing space so the line is as wide as the bottom.

```ts ! pi-logo.ts
/**
 * The pi logo: 4 cells wide and 2 lines tall. Each cell shows two square pixels with half blocks:
 *
 *   coral coral coral .
 *   blue  .     coral .
 *   blue  blue  .     yellow
 *   blue  .     .     yellow
 *
 * The brand colors stay fixed across themes; they follow the terminal's color mode.
 */
export function piLogoLines(): [string, string] {
	const mode = theme.getColorMode();
	const fg = (color: typeof CORAL) => foregroundAnsi(color, mode);
	// The fourth cell of the top line is empty, so it is padded to the same width as the bottom line.
	const top = `${fg(CORAL)}${backgroundAnsi(BLUE, mode)}▀${RESET}${fg(CORAL)}▀█${RESET} `;
	const bottom = `${fg(BLUE)}█▀${RESET} ${fg(YELLOW)}█${RESET}`;
	return [top, bottom];
}
```

## !!steps Terminal support and fallback

Apple Terminal leaves gaps between rows and misaligns half blocks, so `supportsPiLogo` returns false there and callers use `piWordmark`, which colors the letters P and i with the coral and yellow.

```ts ! pi-logo.ts
/**
 * Whether the terminal renders the half-block logo correctly. Apple Terminal draws gaps between rows and
 * misaligns the half blocks, so it gets the text wordmark instead.
 */
export function supportsPiLogo(): boolean {
	return !isAppleTerminalSession();
}

/** Text fallback for the logo: "Pi" with the logo's coral and yellow. */
export function piWordmark(): string {
	const mode = theme.getColorMode();
	return `${foregroundAnsi(CORAL, mode)}P${RESET}${foregroundAnsi(YELLOW, mode)}i${RESET}`;
}
```

</Scrollycoding>

Callers are expected to check `supportsPiLogo` first. Nothing in this file enforces that, so calling `piLogoLines` directly on Apple Terminal would draw the broken version.
