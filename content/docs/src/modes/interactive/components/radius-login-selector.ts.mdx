A generic selector, [extension-selector.ts](/docs/src/modes/interactive/components/extension-selector.ts), draws the top-level login menu. This file subclasses it to add one special effect: while the Radius option is highlighted, its text flows through the four Radius logo colors.

The file says it is internal to interactive mode and the effect is deliberately Radius-only. It is built on color helpers from pi-tui and the theme's color mode in [theme.ts](/docs/src/modes/interactive/theme/theme.ts).

<Scrollycoding>

## !!steps Animation constants

The four logo colors are parsed once. A band is four characters wide, the pattern scrolls at ten characters per second, and the redraw tick is 50 ms.

```ts ! radius-login-selector.ts
/** The four colors of the Radius logo, in the order they stream across the text. */
const RADIUS_COLORS: readonly Color[] = ["#4d9abf", "#83ccd2", "#f1be57", "#f09082"].map((hex) => parseColor(hex));
/** Width of each color band, in characters. */
const CHARS_PER_COLOR = 4;
const CHARS_PER_SECOND = 10;
const ANIMATION_FRAME_MS = 50;
```

## !!steps Computing the shimmer

For each character the position in the color cycle is the index minus a time-based offset, wrapped to be non-negative. The band number picks the start color and the fractional part the blend amount, eased with smoothstep so bands stay recognizable. The result ends with a reset of the foreground color.

```ts ! radius-login-selector.ts
/** Color `text` with the Radius logo colors flowing left to right; `elapsedMs` is the animation time. */
function radiusShimmer(text: string, elapsedMs: number): string {
	const mode = theme.getColorMode();
	const cycle = RADIUS_COLORS.length * CHARS_PER_COLOR;
	const offset = (elapsedMs / 1000) * CHARS_PER_SECOND;
	let result = "";
	let index = 0;
	for (const char of text) {
		const position = (((index - offset) % cycle) + cycle) % cycle;
		const band = Math.floor(position / CHARS_PER_COLOR);
		const t = position / CHARS_PER_COLOR - band;
		// Smoothstep keeps each band recognizable while still blending into the next one.
		const amount = t * t * (3 - 2 * t);
		const from = RADIUS_COLORS[band] as Color;
		const to = RADIUS_COLORS[(band + 1) % RADIUS_COLORS.length] as Color;
		result += foregroundAnsi(mixColors(from, to, amount, "srgb"), mode) + char;
		index++;
	}
	return `${result}\x1b[39m`;
}
```

## !!steps A subclass with a timer

The constructor wraps the select and cancel callbacks so they stop the animation first, then starts a 50 ms interval. The interval only requests a render while `animating` is true, and `unref` keeps it from holding the process open.

```ts ! radius-login-selector.ts
class RadiusLoginMenuComponent extends ExtensionSelectorComponent {
	private readonly radiusOption: RadiusOption;
	private readonly animationStart = performance.now();
	private animationTimer: ReturnType<typeof setInterval> | undefined;
	private animating = false;

	constructor(
		tui: TUI,
		title: string,
		options: string[],
		radiusOption: RadiusOption,
		onSelect: (option: string) => void,
		onCancel: () => void,
	) {
		super(
			title,
			options,
			(option) => {
				this.stopAnimation();
				onSelect(option);
			},
			() => {
				this.stopAnimation();
				onCancel();
			},
		);
		this.radiusOption = radiusOption;
		this.animationTimer = setInterval(() => {
			if (this.animating) tui.requestRender();
		}, ANIMATION_FRAME_MS);
		this.animationTimer.unref?.();
	}
```

## !!steps Swapping one rendered line

`render` calls the parent, then renders the line the parent would draw for the selected Radius option and looks for it by exact match. If found, that line is replaced with the animated one; if the style changed or the label wrapped, nothing matches and the option renders normally. That also sets `animating`, so the timer idles when Radius is not selected.

```ts ! radius-login-selector.ts
	override render(width: number): string[] {
		const lines = super.render(width);
		const { label, text } = this.radiusOption;
		const selectedLine = new Text(theme.fg("accent", "→ ") + theme.fg("accent", label), 1, 0).render(width)[0];
		const index = selectedLine === undefined ? -1 : lines.indexOf(selectedLine);
		this.animating = index >= 0;
		if (this.animating) {
			const shimmer = radiusShimmer(text, performance.now() - this.animationStart);
			const animatedLine = theme.fg("accent", "→ ") + shimmer + label.slice(text.length);
			lines[index] = new Text(animatedLine, 1, 0).render(width)[0] ?? "";
		}
		return lines;
	}
```

## !!steps Cleanup and factory

`dispose` stops the timer before calling the parent. `createLoginMenuSelector` is the only export.

```ts ! radius-login-selector.ts
	private stopAnimation(): void {
		clearInterval(this.animationTimer);
		this.animationTimer = undefined;
		this.animating = false;
	}

	override dispose(): void {
		this.stopAnimation();
		super.dispose();
	}
}

/** Top-level `/login` selector whose Radius option shimmers in the Radius logo colors while it is selected. */
export function createLoginMenuSelector(
	tui: TUI,
	title: string,
	options: string[],
	radiusOption: RadiusOption,
	onSelect: (option: string) => void,
	onCancel: () => void,
): ExtensionSelectorComponent {
	return new RadiusLoginMenuComponent(tui, title, options, radiusOption, onSelect, onCancel);
}
```
