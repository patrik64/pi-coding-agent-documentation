Radius is a gateway that the built-in provider of the same name signs in to. This file centralizes its identity: the provider id, the environment variable that overrides the gateway origin, the default MCP endpoint, and a function returning the effective gateway URL.

The URL normalization and default come from the pi-ai package. The bug report flow in [bug-report.ts](/docs/src/modes/interactive/bug-report.ts) and [bug-report-upload.ts](/docs/src/core/bug-report-upload.ts) uploads to the gateway URL; [interactive-mode.ts](/docs/src/modes/interactive/interactive-mode.ts) and `pi auth login` in [auth-login.ts](/docs/src/cli/auth-login.ts) recognise a Radius login by the provider id; and [radius-mcp.ts](/docs/src/core/radius-mcp.ts) uses the MCP endpoint to point the Radius MCP server at that login.

<Scrollycoding>

## !!steps Identity constants

`RADIUS_PROVIDER_ID` is the provider id used for credentials and models. `RADIUS_MCP_URL` is computed once at import time from the default gateway, so it ignores the environment override.

```ts ! radius.ts
import { DEFAULT_RADIUS_GATEWAY, normalizeRadiusGatewayUrl } from "@earendil-works/pi-ai/providers/radius-config";

export const RADIUS_PROVIDER_ID = "radius";
export const ENV_RADIUS_GATEWAY = "PI_RADIUS_GATEWAY";
/** MCP endpoint of the gateway the built-in Radius provider signs in to. */
// !mark
export const RADIUS_MCP_URL = `${normalizeRadiusGatewayUrl(DEFAULT_RADIUS_GATEWAY)}/mcp`;
```

## !!steps Honoring the override

`getRadiusGatewayUrl` reads `PI_RADIUS_GATEWAY` on every call, falling back to the default, and normalizes either. Because it reads the environment lazily, tests and wrappers can change the variable after startup.

```ts ! radius.ts
/** Radius gateway origin, honoring the `PI_RADIUS_GATEWAY` override. */
export function getRadiusGatewayUrl(): string {
// !mark
	return normalizeRadiusGatewayUrl(process.env[ENV_RADIUS_GATEWAY] ?? DEFAULT_RADIUS_GATEWAY);
}
```

</Scrollycoding>

Worth noting the asymmetry: the MCP URL is fixed at module load while the gateway URL is dynamic, so a custom gateway does not change the MCP endpoint that [radius-mcp.ts](/docs/src/core/radius-mcp.ts) writes into `mcp.json`. In this package the override only redirects bug report uploads.
